# Icy Tower - لعبة القفز العمودي

## 📋 نظرة عامة على المشروع

مشروع لعبة Icy Tower هو تطبيق تفاعلي ثنائي الأبعاد (2D) تم تطويره باستخدام تقنيات الكمبيوتر جرافيكس الحديثة. اللعبة مستوحاة من اللعبة الكلاسيكية Icy Tower وتم بناؤها بالكامل باستخدام HTML5 Canvas API و JavaScript.

## 🎯 أهداف المشروع

1. تطبيق مفاهيم الكمبيوتر جرافيكس في بيئة تفاعلية
2. استخدام Canvas API لرسم العناصر الرسومية
3. تطبيق نظام الفيزياء (Physics Engine) للحركة والجاذبية
4. إنشاء نظام كاميرا متحرك (Camera System)
5. تطوير واجهة مستخدم تفاعلية (Interactive UI)
6. دمج المؤثرات الصوتية والبصرية

## 🛠️ التقنيات المستخدمة

### اللغات والتقنيات الأساسية
- **HTML5**: هيكل الصفحة وعنصر Canvas
- **CSS3**: تنسيق الواجهة والرسوم المتحركة
- **JavaScript (ES6+)**: منطق اللعبة والبرمجة الكائنية (OOP)
- **Canvas API**: رسم العناصر الرسومية ثنائية الأبعاد

### المكتبات والأدوات
- **Web Audio API**: تشغيل المؤثرات الصوتية
- **LocalStorage API**: حفظ أعلى النقاط
- **RequestAnimationFrame**: حلقة اللعبة (Game Loop)

## 🎮 مميزات اللعبة

### 1. نظام الفيزياء المتقدم
- **الجاذبية الأرضية**: محاكاة واقعية لتأثير الجاذبية على اللاعب
- **الاحتكاك**: نظام انزلاق يحاكي الحركة على الجليد
- **الارتداد من الجدران**: ارتداد اللاعب عند الاصطدام بالحواف
- **القفز المتغير**: ارتفاع القفز يعتمد على مدة الضغط على الزر

### 2. نظام الكاميرا الديناميكي
- كاميرا تتبع اللاعب بسلاسة (Smooth Camera Follow)
- حركة الكاميرا العمودية مع صعود اللاعب
- نظام Smoothing لتجنب الحركة المفاجئة

### 3. نظام الكومبو والنقاط
- حساب النقاط بناءً على عدد الأدوار المتخطاة
- نظام كومبو متدرج مع مضاعفات أسية
- 9 مستويات من رسائل الكومبو (Good, Sweet, Great, Super, WOW, Amazing, EXTREME, Fantastic, UNBELIEVABLE)
- مؤثرات صوتية مختلفة لكل مستوى

### 4. المؤثرات البصرية

#### أ. نظام الديسكو (Disco Mode)
- يتم تفعيله عند تحقيق رقم قياسي في الكومبو
- تغيير ألوان الخلفية بشكل ديناميكي
- تأثيرات إضاءة على المنصات واللاعب
- نص متحرك "DISCO MODE!" مع توهج ملون
- 8 ألوان متدرجة تتغير تلقائياً

#### ب. تأثيرات الدوران
- دوران اللاعب 360° أثناء القفز
- سرعة الدوران تعتمد على سرعة الحركة
- دوران أسرع للقفزات الخارقة (Super Jump)

#### ج. تأثيرات التوهج
- توهج أصفر للقفزات الخارقة
- توهج ملون في وضع الديسكو
- ظلال ثلاثية الأبعاد للمنصات

### 5. نظام المنصات الديناميكي
- توليد عشوائي للمنصات
- 5 أنواع مختلفة من المنصات (خشب، جليد، حجر، معدن، كريستال)
- صعوبة متدرجة (المنصات تصبح أضيق مع الارتفاع)
- تأثيرات ثلاثية الأبعاد (3D Effects)
- حواف مستديرة وزخارف

### 6. نظام الصوت المتقدم
- **أصوات القفز**: 3 أصوات مختلفة حسب السرعة (منخفض، متوسط، عالي)
- **أصوات الكومبو**: 9 أصوات متدرجة حسب عدد الأدوار
- **صوت الحافة**: يتم تشغيله عند الاقتراب من السقوط
- **أصوات الجماهير**: عند تحقيق رقم قياسي (aight/cheer)
- **صوت السقوط**: عند خسارة اللعبة

### 7. واجهة المستخدم (UI)
- قائمة رئيسية (Main Menu)
- شاشة اللعب مع عدادات:
  - عداد الأدوار (Floor Counter)
  - عداد النقاط (Score Counter)
  - عداد الكومبو مع شريط توقيت
- شاشة نهاية اللعبة (Game Over) مع الإحصائيات
- حفظ أعلى نقاط (High Score)

### البرمجة الكائنية (OOP)

#### 1. Class: Player
**المسؤوليات:**
- إدارة موقع وحركة اللاعب
- تطبيق الفيزياء (الجاذبية، الاحتكاك، السرعة)
- معالجة القفز والارتداد من الجدران
- رسم اللاعب مع التأثيرات البصرية
- حساب الأدوار المتخطاة

**الخصائص الرئيسية:**
- `x, y`: الموقع
- `velocityX, velocityY`: السرعة
- `isGrounded`: هل اللاعب على الأرض
- `isSuperJump`: هل القفزة خارقة
- `rotation`: زاوية الدوران

#### 2. Class: PlatformManager
**المسؤوليات:**
- توليد المنصات بشكل عشوائي
- إدارة صعوبة اللعبة
- رسم المنصات مع التأثيرات
- حذف المنصات البعيدة
- تحديد الدور الحالي للاعب

**الخصائص الرئيسية:**
- `platforms[]`: مصفوفة المنصات
- `difficultyFactor`: معامل الصعوبة
- `platformTypes[]`: أنواع المنصات

#### 3. Class: Camera
**المسؤوليات:**
- تتبع حركة اللاعب
- حساب موقع الكاميرا
- تطبيق Smoothing للحركة

#### 4. Class: ComboSystem
**المسؤوليات:**
- حساب الكومبو والنقاط
- إدارة مؤقت الكومبو
- تحديد رسائل الكومبو
- تتبع الأرقام القياسية

#### 5. Class: SoundManager
**المسؤوليات:**
- تحميل الأصوات
- تشغيل الأصوات المناسبة
- إدارة مستوى الصوت

#### 6. Class: UI
**المسؤوليات:**
- تحديث العدادات
- إظهار/إخفاء القوائم
- عرض رسائل الكومبو
- إدارة شاشة نهاية اللعبة

#### 7. Class: InputHandler
**المسؤوليات:**
- معالجة مدخلات لوحة المفاتيح
- تحديث حالة اللاعب

#### 8. Class: Game
**المسؤوليات:**
- تنسيق جميع الأنظمة
- إدارة حالة اللعبة (Menu, Playing, GameOver)
- حلقة التحديث (Update Loop)
- حلقة الرسم (Render Loop)
- إدارة وضع الديسكو

## 🎨 مفاهيم الكمبيوتر جرافيكس المطبقة

### 1. Canvas Rendering
```javascript
ctx.fillRect(x, y, width, height)        // رسم مستطيلات
ctx.drawImage(image, x, y, w, h)         // رسم صور
ctx.beginPath() / ctx.stroke()           // رسم خطوط
ctx.arc(x, y, radius, 0, Math.PI * 2)   // رسم دوائر
```

### 2. Transformations (التحويلات الهندسية)
```javascript
ctx.translate(x, y)      // الإزاحة
ctx.rotate(angle)        // الدوران
ctx.scale(sx, sy)        // التكبير/التصغير
ctx.save() / ctx.restore() // حفظ/استرجاع الحالة
```

### 3. Gradients (التدرجات اللونية)
```javascript
const gradient = ctx.createLinearGradient(x0, y0, x1, y1)
gradient.addColorStop(0, color1)
gradient.addColorStop(1, color2)
```

### 4. Shadows and Glow Effects (الظلال والتوهج)
```javascript
ctx.shadowColor = color
ctx.shadowBlur = blur
```

### 5. Bezier Curves (منحنيات بيزيه)
```javascript
ctx.quadraticCurveTo(cpx, cpy, x, y)  // للحواف المستديرة
```

### 6. Alpha Blending (الشفافية)
```javascript
ctx.fillStyle = 'rgba(r, g, b, alpha)'
```

## 🎯 الخوارزميات المستخدمة

### 1. خوارزمية الفيزياء
```
السرعة الجديدة = السرعة القديمة + التسارع × الوقت
الموقع الجديد = الموقع القديم + السرعة × الوقت
```

### 2. خوارزمية كشف الاصطدام (Collision Detection)
```
AABB (Axis-Aligned Bounding Box):
if (playerRight > platformLeft && 
    playerLeft < platformRight &&
    playerBottom >= platformTop &&
    playerBottom <= platformBottom)
    then COLLISION
```

### 3. خوارزمية Camera Smoothing
```
الموقع الجديد = الموقع القديم + (الهدف - الموقع القديم) × معامل التنعيم
```

### 4. خوارزمية حساب النقاط
```
النقاط الأساسية = عدد الأدوار × 10
مضاعف الكومبو = 1.5 ^ (الكومبو - 1)
النقاط النهائية = النقاط الأساسية × مضاعف الكومبو
```

## 🎮 طريقة اللعب

### التحكم
- **السهم الأيسر / A**: الحركة لليسار
- **السهم الأيمن / D**: الحركة لليمين
- **مسافة / السهم الأعلى / W**: القفز
  - اضغط مطولاً للقفز أعلى
  - اضغط بسرعة للقفز المنخفض

### الهدف
- الصعود لأعلى مسافة ممكنة
- تخطي أكبر عدد من الأدوار في قفزة واحدة
- تحقيق أعلى نقاط وأطول كومبو
- تجنب السقوط أو الوصول لخط الموت

### نصائح
1. استخدم السرعة لتحقيق قفزات أعلى
2. ارتد من الجدران لزيادة السرعة
3. حاول تخطي أكبر عدد من الأدوار لزيادة النقاط
4. انتبه لصوت الحافة - يعني أنك على وشك السقوط!
